## 一句话定位

本插件补的是 `@deepseek-ai/dsh-mcp-client` **缺失的管理面**：官方插件按「一行一个 MCP 服务器」静态挂在
`cordis.patch.yml` 里，增删要改文件、要重启；本插件在 **设置 → 侧栏** 给了一个面板，
把「列出 / 添加 / 改写 / 启停 / 删除」做完，**点保存才写盘、写完不重启**。

它**不**替换官方的传输实现、**不**做协议层探活、**不**接管你手写的那两行（只能改写凭据族字段与启停）。
