# 图片与截图资产

**目前本目录只有这份说明，没有实际图片。**

面板的界面与行为以 `README.md` 的文字与表格为准（10 步验证表 + 状态列对照表），
不依赖截图成立 —— 这是刻意的：截图会随主题、语言、服务器数量变化，容易变成"和文档对不上"的第二个真源。

## 如果要补截图，请遵守下面三条

1. **不得出现真实凭据**：`url` 的查询串、`env` 的值、任何 key 片段都不许入图；
   建议面板里只留**演示用**的假服务器（例如 `serverName: demo`、`url: https://mcp.example.com/mcp`）。
2. **不得出现含用户名的绝对路径**：面板顶部显示的是符号化路径（`$DSH_HOME\…`），
   截图前确认没有被别的工具栏/标题栏带出来。
3. **命名与内容**：`<场景>-<语言>.png`（例如 `panel-list-zh.png`），
   并在此文件里按「场景 → 文件名 → 该图证明了什么」三列登记。
